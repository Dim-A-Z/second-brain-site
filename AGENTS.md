# Repository Instructions

Before implementation, read `docs/PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/DATA_MODEL.md`, and the active OpenSpec change.

- Show a concise plan before making changes.
- Keep changes within the approved OpenSpec scope.
- Run the relevant OpenSpec validation and Astro build checks.
- Do not stage, commit, or push unless explicitly requested.
- `_reference/` is local-only input and must never be committed or published.
- User-facing content may be in Russian; technical files, comments, and identifiers must be in English.
- Never expose private-note metadata through the public site.
- Prefer simple, reusable content-driven implementation over page-specific markup.
