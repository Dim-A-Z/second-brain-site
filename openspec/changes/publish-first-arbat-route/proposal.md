## Why

The new public repository needs one complete, reusable publishing slice that proves Markdown content can produce a useful static route page without coupling the public site to private notes.

## What Changes

- Introduce public Place and Route Markdown collections.
- Publish the nine-stop Arbat architecture route as a static page.
- Add reusable route-stop presentation and a progressively enhanced interactive map.
- Add external map navigation derived from the ordered route coordinates.
- Preserve route-level editorial interludes and optional starred bonus locations.
- Add a minimal home page linking to the route.
- Establish public-safety boundaries for local reference material and optional publication links.

## Capabilities

### New Capabilities

- `route-page`: Static, content-driven route pages with ordered reusable places, field-guide details, optional publications, an interactive map, and mobile usability.

### Modified Capabilities

None.

## Impact

This adds an Astro static site, Astro Content Collections, Leaflet browser assets, a locally bundled Manrope font, public Markdown content, responsive styles, and repository documentation. It adds no backend, server adapter, database, or private repository integration.
