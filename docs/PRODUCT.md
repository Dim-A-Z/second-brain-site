# Product

This repository contains a public, Markdown-first personal knowledge and publishing site.

## MVP

The first public content types are:

- **Place**: a researched location with practical field-guide information.
- **Route**: an ordered walk assembled from reusable places.

The first published artifact is the Moscow architecture route “От Арбата к первому вертикальному городу”. Route pages may later link to place articles, Dzen articles, podcast episodes, reels, and other publications. Optional publications that are absent must not render.

Additional content types, publication automation, search, accounts, administration, and private knowledge features are outside this task.
